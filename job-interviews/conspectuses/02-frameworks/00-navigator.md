# Frameworks: навигатор

Раздел для подготовки к интервью по PHP-фреймворкам и тестовым инструментам.

## Файлы

1. `01-laravel-internals-di-middleware-eloquent-queues.md` - Laravel request lifecycle, service container, providers, middleware, routing, validation, config, Eloquent, transactions, migrations, queues, retries, idempotency и Laravel testing specifics.
2. `02-symfony-internals-di-httpkernel-doctrine-messenger.md` - Symfony HttpKernel, EventDispatcher, compiled DI container, bundles, routing, validation, config, Doctrine, transactions, migrations, Messenger, retries, idempotency и Symfony testing specifics.
3. `03-php-testing-frameworks-phpunit-codeception-pest.md` - стратегия тестирования PHP backend: test pyramid, unit/integration/functional/e2e/contract tests, doubles, fixtures, DB testing, async testing, API tests, legacy, flaky, mutation testing, coverage, CI, PHPUnit, Codeception, Pest.

## Как повторять

1. Если вакансия Laravel-heavy: сначала Laravel-конспект, затем testing-конспект.
2. Если вакансия Symfony-heavy: сначала Symfony-конспект, затем testing-конспект.
3. Если интервью общее Senior/Lead PHP: прочитать все три файла и отдельно проговорить короткие ответы.
